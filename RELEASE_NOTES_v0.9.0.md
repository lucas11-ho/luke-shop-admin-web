# Luke Shop Admin Web v0.9.0 — Merchant Operations Completion

This release turns previously hidden/partial backend capability into explicit merchant controls.

## Added or completed

- Stores workspace with approved Store Designer template selection.
- Merchant profile/password/session management.
- Tenant audit viewer.
- Category edit manager.
- Modifier group/option edit and deactivate controls.
- Inventory location edit/default/status controls.
- Promotion code edit/deactivate and promotion-target removal.
- Payment method provider-key/public-config/sort controls.
- Professional refund request/control modals with audit reason, provider reference and failure reason fields.
- Delivery public configuration editor.
- Luke CS credential revocation.
- Rich customer detail with addresses, lifecycle history, recent orders and active sessions.

Refund UI explicitly distinguishes Luke's recorded workflow from actual provider money movement.
