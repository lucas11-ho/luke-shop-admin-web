# Deployment Checklist — Merchant Admin v0.10.0

Prerequisite: Backend v0.12.0 and migration 013.

- Deploy the existing Cloudflare project for `luke-shop-admin-web`.
- Confirm API base URL still points to the production Luke Shop backend.
- Verify Customer Experience loads status visual packs.
- Verify an order with GPS shows precise delivery location and accuracy.
- Verify a live-sharing order shows the live point/last ping.
- Verify fulfillment updates can set separate ready/delivery ETA values.
- Verify existing Store Designer draft/publish flow still works.
