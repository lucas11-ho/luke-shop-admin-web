# Luke Shop Admin Web v0.6.1 — Customer Experience Builder UX Polish

Polishes Customer Experience with feature toggles already supported by Backend v0.8.0, section image/CTA/limit controls already normalized by the existing schema, a refined expandable home builder, richer preview, responsive layout, and accessibility focus states. No API or database changes.

## Compatibility

- Backend: v0.8.0 unchanged
- Database migrations: unchanged through 009
- Tenant routing/auth/permissions: unchanged
- Existing `.env` and `package-lock.json` must be preserved by the upgrade installer.
