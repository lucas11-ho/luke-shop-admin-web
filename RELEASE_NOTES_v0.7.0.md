# Release Notes v0.7.0 — Advanced Store Designer + Promotion/Order Operations

- Store Designer now consumes the canonical server template + typography catalog.
- Expanded theme tokens, template modes, layouts and approved font presets including iPhone/iOS System.
- Promotion editor now uses a compact calendar popover + time picker and tenant timezone scheduling.
- Order detail uses backend-provided valid next transitions rather than an unrestricted status selector.
- Raw JSON-first settings are replaced by readable controls.
