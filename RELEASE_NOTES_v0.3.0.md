# Release Notes — Luke Shop Admin Web v0.3.0

## Advanced Commerce Operations UI

- Adds a full product operations workspace with product editing, publishing, fulfillment modes, variant/SKU creation and activation, media attachment, restaurant modifier groups/options, and inventory visibility.
- Adds inventory ledger and inventory-location management.
- Replaces the basic order modal with an order workspace containing items, totals, address snapshot, adjustments, payment actions, fulfillment tracking, and status history.
- Adds editable payment-method and delivery-method configuration.
- Adds payment attempt detail.
- Adds a full promotion workspace with scheduling/limits, coupon codes, and product/category/order targets.
- Expands customer detail and status operations.
- Expands the dashboard into an operational attention center.
- Adds functional JSON editors for tenant branding, modules, and customer-service configuration.
- Retains v0.2.0 Staff/RBAC and Luke CS/AI controls.

No backend release or database migration is included. Backend v0.6.0+ is required.
